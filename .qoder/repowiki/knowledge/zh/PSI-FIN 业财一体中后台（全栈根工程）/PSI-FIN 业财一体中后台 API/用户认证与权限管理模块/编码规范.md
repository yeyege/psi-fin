- Router 层保持极简：只负责参数解析、调用 service 方法并以 `{code, message, data}` 格式统一返回。
- 鉴权通过 FastAPI 依赖注入实现：`get_current_user` 解析 `Authorization: Bearer` 头并抛 `HTTPException`，`require_admin` 在其基础上校验角色，接口以 `_: User = Depends(require_admin)` 声明。
- 密码不存明文：新建/更新用户时一律通过 `hash_password` 生成 `salt$digest` 格式的 hash，校验使用 `verify_password` 配合 `hmac.compare_digest` 防时序攻击。
- 管理员保护：更新或删除用户前检查是否会影响最后一个启用管理员，若会则抛出 `BusinessError`（409）。
- Token 生命周期：登录时生成随机 token 写入 `auth_tokens` 并设置 `expires_at`，登出直接删除对应记录，查询时同时清理过期 token。
