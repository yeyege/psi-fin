模块按三层划分：`app/models/auth.py` 定义 SQLAlchemy 模型 `User`（含 role/status 字段）与 `AuthToken`（随机 token + 过期时间），并集中声明角色常量 `ROLE_ADMIN/ROLE_OPERATOR` 与状态常量 `STATUS_ACTIVE/STATUS_INACTIVE`；`app/services/auth_service.py` 封装所有业务逻辑——密码哈希/校验（PBKDF2-SHA256, 100k 轮）、用户 CRUD、登录签发 Token、登出撤销、以及两个 FastAPI 依赖函数 `get_current_user`（解析 `Authorization: Bearer <token>` 并校验活跃状态）和 `require_admin`（在已登录基础上校验 admin 角色）；`app/routers/auth.py` 仅做 HTTP 路由薄层，通过 `Depends(get_db)` 注入数据库会话，调用 service 层并统一返回 `{code, message, data}` 结构。依赖方向单向：routers → services → models/database，鉴权逻辑集中在 service 的依赖函数中，由 router 通过 `Depends` 复用。
