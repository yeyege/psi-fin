- 路由函数通过 `Depends(get_current_user)` 在 `APIRouter` 级别声明鉴权依赖，所有端点共享同一认证上下文。
- 数据库会话统一通过 `Depends(get_db)` 注入，避免在每个 handler 中手动管理连接生命周期。
- HTTP 响应统一返回形如 `{code, message, data}` 的字典，并使用 Pydantic 泛型 `ApiResponse[PageResult[T]]` 声明响应模型。
- 分页查询参数固定为 `keyword`、`page`、`pageSize`（别名 page_size），并在服务层以 `(page-1)*page_size` 计算 offset 配合 limit 实现。
- 资源创建前进行唯一性校验（如客户编码重复），失败时抛出 `BusinessError` 携带错误消息与状态码。
- 删除操作采用软删除策略，将实体 status 字段设为 INACTIVE 而非物理删除，以保留历史单据可追溯性。
