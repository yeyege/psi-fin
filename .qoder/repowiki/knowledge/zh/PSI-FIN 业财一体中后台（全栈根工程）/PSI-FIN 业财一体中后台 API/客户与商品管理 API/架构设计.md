模块采用清晰的分层结构：`routers/customers.py` 与 `routers/products.py` 作为 HTTP 入口，各自定义 `/api/customers` 和 `/api/products` 路由组，统一通过 `Depends(get_current_user)` 实现鉴权、`Depends(get_db)` 注入 SQLAlchemy Session；路由函数仅做参数解析并委托给 `app.services` 下的对应 service（如 `customer_service`、`product_service`）。`services/customer_service.py` 是领域服务层，直接操作 `app.models.Customer` 模型，实现分页列表、按关键字模糊匹配、唯一性校验、增量更新与软删除（将 status 置为 INACTIVE）等核心业务规则。依赖方向单向自上而下：router → service → models/database，schema 类型由 `app.schemas` 中的 Pydantic 模型约束入参与响应。
