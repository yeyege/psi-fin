模块按三层组织：`app/models/orders.py` 使用 SQLAlchemy ORM 定义 InboundOrder/OutboundOrder/Wave/PickingOrder/ReturnOrder/StockTransfer/StockAdjustment/CycleCount 及其明细表，通过 `relationship` + `cascade="all, delete-orphan"` 维护主从关系；`app/schemas/orders.py` 基于继承自 `CamelModel` 的 Pydantic v2 模型定义各单据的请求/响应结构，使用 `Field` 约束与 `field_validator` 做入参校验；`app/routers/sales_orders.py` 仅作为薄 HTTP 层，通过 `APIRouter(tags=["销售订单"])` 注册 `/api/sales-orders` CRUD 及 confirm/ship/complete/cancel 状态流转端点，所有业务逻辑委托给 `app.services.finance_service`，并统一依赖 `get_current_user` 鉴权与 `get_db` 会话注入。依赖方向单向：routers → services → models/schemas，本模块不直接操作数据库。
