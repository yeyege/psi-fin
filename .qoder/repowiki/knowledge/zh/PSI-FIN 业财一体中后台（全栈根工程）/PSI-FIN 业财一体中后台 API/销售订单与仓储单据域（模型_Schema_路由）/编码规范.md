- 每个单据采用「主表模型 + Item 明细模型」配对，明细通过 ForeignKey 关联主表并使用 cascade="all, delete-orphan" 实现级联删除。
- Schema 统一继承 `CamelModel`，字段通过 `Field(...)` 声明必填、长度、取值范围与描述，复杂校验使用 `@field_validator`。
- 路由函数保持极简：只解析参数、调用对应 service 方法、返回固定结构的 `{code, message, data}` JSON，不写业务判断。
- 所有状态以字符串枚举列（如 PENDING/COMPLETED/PICKED/SHIPPED）表示，并在模型注释中写明状态机流转方向。
- 列表查询通过 Query 参数支持分页（page/pageSize）与多条件过滤（status/customer_id/keyword），默认 page_size=20 且限制 1~100。
