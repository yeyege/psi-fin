- 每个路由函数统一返回 `{"code": 200, "message": "success", "data": ...}` 的标准响应结构。
- 路由通过 `APIRouter(tags=[...], dependencies=[Depends(get_current_user)])` 集中声明标签与全局鉴权依赖。
- 数据库会话以 `db: Session = Depends(get_db)` 形式作为路由参数注入，service 方法仅接收 `Session` 不持有连接。
- Service 内部将重复的计数/过滤逻辑抽取为局部辅助函数（如 `_today_count`、`_status_count`）以减少重复查询代码。
