模块由两层组成：路由层（`routers/dashboard.py`、`routers/executive.py`）基于 FastAPI `APIRouter` 暴露 `/api/dashboard/*` 与 `/api/executive/*` 接口，所有路由通过 `dependencies=[Depends(get_current_user)]` 强制鉴权，并使用 `get_db` 注入 SQLAlchemy Session；服务层（`services/dashboard_service.py`）封装具体的聚合查询逻辑，直接操作 `app.models` 中的 `Product`、`Customer`、`Inventory`、`InboundOrder`、`OutboundOrder` 等 ORM 模型，使用 `sqlalchemy.func` 进行汇总统计。`executive.py` 进一步委托给 `finance_service` 完成应收、账龄、趋势等财务指标计算，体现“路由仅负责参数校验与响应包装，业务聚合下沉到 service”的分层边界。
