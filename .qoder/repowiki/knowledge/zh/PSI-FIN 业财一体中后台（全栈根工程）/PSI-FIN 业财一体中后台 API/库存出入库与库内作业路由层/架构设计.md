本模块由三个并列的 FastAPI `APIRouter` 组成：`inbound.py`（入库单，状态机 PENDING→COMPLETED）、`outbound.py`（出库单，状态机 PENDING→PICKED→REVIEWED→SHIPPED）、`transfers.py`（库内移库与库存调整）。每个 router 通过 `dependencies=[Depends(get_current_user)]` 统一鉴权，并通过 `get_db` 注入 SQLAlchemy Session；请求体使用 `app.schemas` 中的 Pydantic 模型校验，核心业务全部委派给 `app.services` 下的 `inbound_service`、`outbound_service`、`transfer_service`、`adjustment_service`，路由层仅负责参数绑定、调用 service 并返回统一的 `{code, message, data}` JSON 响应格式。列表接口统一支持 `status`、`page`、`pageSize` 分页参数，资源操作遵循 RESTful 风格（POST 创建、GET 列表/详情、POST 子资源触发状态变更如 `/receive`、`/pick`、`/review`、`/ship`）。
