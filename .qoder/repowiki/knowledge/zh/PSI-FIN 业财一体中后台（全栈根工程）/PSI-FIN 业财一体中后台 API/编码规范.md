- 每个业务域拆分为 routers/schemas/services/models 四层，路由仅负责参数校验与委托 service，service 封装事务与领域规则，models 使用 SQLAlchemy 异步声明式映射。
- 统一通过 `app.common.errors.BusinessError` 抛出业务异常，并由 `main.py` 中的全局异常处理器转换为 `{detail, message, data}` 格式的 JSON 响应。
- 所有路由通过 `app.include_router` 在 `main.py` 中集中注册，新增功能需在此处显式挂载才能对外暴露。
- 测试基于 `tests/conftest.py` 提供的异步客户端与内存数据库夹具，使用 httpx.AsyncClient 发起 HTTP 级断言而非直接调用函数。
