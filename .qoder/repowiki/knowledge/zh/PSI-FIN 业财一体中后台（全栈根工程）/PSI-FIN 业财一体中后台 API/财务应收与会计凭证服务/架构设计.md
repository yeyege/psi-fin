模块按 FastAPI 路由层 + 业务服务层的双层组织：`routers/finance.py` 仅暴露 `/api/finance/*` 端点，通过 `get_current_user` 鉴权依赖并委托 `app.services.finance_service`；`services/finance_service.py` 实现销售订单状态机（DRAFT→CONFIRMED→SHIPPED→COMPLETED/CANCELLED）、发货时幂等生成应收（`_generate_receivable` 以 `source_order_no+entry_type` 唯一约束兜底并发）、收款登记与多目标部分核销（`FinanceSettlement` 关联表维护核销明细）、按到期日实时计算账龄分段及经营驾驶舱聚合；`services/accounting_service.py` 作为独立会计内核，封装科目树（`Account` 父子编码前缀校验、`is_leaf` 控制）、会计期间（`Period` 开放/结账/倒序反结账）与凭证生命周期（`create_voucher/post_voucher/reverse_voucher/delete_draft_voucher`），过账强制借贷平衡（EPS=1e-6 容差）且已过账凭证禁止改删，冲销采用红字反向分录并双向关联 `reverses_voucher_no`/`reversed_voucher_no`。两服务均通过 SQLAlchemy Session 直接操作模型，错误统一抛出 `BusinessError` 并附带 HTTP 状态码，金额统一保留两位小数。
