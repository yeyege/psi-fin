根目录作为全栈编排层，不承载业务代码，而是把三个子模块（backend-python / frontend-vue / docs_and_site）串联起来：
- 开发期通过 `package.json` 的 `concurrently` 脚本同时拉起后端 uvicorn 与前端 Vite dev server，实现前后端联调。
- 运行期由 `docker-compose.yml` 编排 MySQL、后端与前端（nginx 反代 `/api`），并通过环境变量注入数据库连接串与服务发现。
- 部署期由 `render.yaml` 声明式定义 PostgreSQL、Python Web Service 与静态站点三资源，自动拉取仓库并构建发布。
- 前后端契约由后端的 Pydantic schemas + camelCase 响应统一约定，前端通过 `VITE_API_BASE` 切换 Mock/真后端，使同一份前端既可独立 GitHub Pages 演示，也可对接真实 API。
- CI（GitHub Actions）在根级别并行执行后端 pytest、前端 build/vitest 与 Docker 镜像校验，保证三子模块变更的一致性。
