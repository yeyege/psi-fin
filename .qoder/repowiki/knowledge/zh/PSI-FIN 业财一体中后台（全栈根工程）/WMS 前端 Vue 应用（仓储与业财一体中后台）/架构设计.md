应用以 `src/main.ts` 为入口，全局挂载 Pinia、vue-router 与 Element Plus 图标；`src/router/index.ts` 集中声明所有路由并通过 `beforeEach` 实现基于 `psifin_token`/`psifin_user` 的登录态校验与 `/users` 管理员权限拦截，将 `/executive` 重定向至 `/bi` 完成旧驾驶舱并入 BI 工作台。API 层 `src/api/index.ts` 通过 `client.ts` 封装 HTTP 客户端，按领域（商品/客户/库存/入库/出库/退货/波次/调拨/盘点/销售订单/财务/经营驾驶舱）导出类型与函数，被各业务视图与 BI 面板共同引用。状态管理采用分层：`stores/user.ts` 保存用户信息，`composables/useBiState.ts` 提供跨 BI 面板共享的筛选/面板状态，组件 `components/BiChart.vue`、`BiModal.vue`、`SummaryCards.vue` 作为通用图表与弹窗被 BI 子模块复用。构建产物由 Vite 生成并部署到 nginx 容器，E2E 测试使用 Playwright 覆盖关键业务流程。
