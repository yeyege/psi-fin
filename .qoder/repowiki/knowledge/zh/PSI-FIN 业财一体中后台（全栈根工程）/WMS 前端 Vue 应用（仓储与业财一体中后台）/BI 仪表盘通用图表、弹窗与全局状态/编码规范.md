- 组件通过 `defineProps` / `defineEmits` 声明强类型接口，并以 `update:*` 形式实现 v-model 双向绑定（如 BiModal 的 `update:visible`）。
- 外部副作用（ECharts 实例、ResizeObserver、window 事件监听）统一在 `onMounted` 中注册并在 `onBeforeUnmount` 中清理，避免内存泄漏。
- 全局状态以模块级 `reactive` 单例暴露，对外仅提供 `readonly(state)` 与显式 setter，禁止直接修改 state。
- 弹窗与图表容器通过 CSS class 前缀 `bi-*`（如 `.bi-scope`、`.bi-modal-root`、`.bi-chart`）进行样式与作用域隔离。
