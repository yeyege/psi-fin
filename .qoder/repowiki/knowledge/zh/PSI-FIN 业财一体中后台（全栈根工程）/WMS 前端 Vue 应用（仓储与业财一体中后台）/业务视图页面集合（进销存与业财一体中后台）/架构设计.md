本模块为前端 Vue 应用的顶层视图层（`src/views/*`），每个 `.vue` 文件对应一个路由页面，采用 `<script setup lang="ts">` 单文件组件模式，通过 `@/api` 统一调用后端 REST 接口获取数据，通过 `@/stores/user` 管理登录态，通过 `vue-router` 进行页面跳转。页面按职责分为三类：
- 认证入口：`LoginView.vue` 独立承担登录与服务冷启动预热逻辑，不依赖布局壳。
- 数据展示型：`DashboardView.vue`、`ExecutiveView.vue`、`FinanceView.vue` 使用 ECharts 渲染图表，配合 `SummaryCards` 组件展示 KPI。
- CRUD 列表型：`ProductsView.vue`、`WarehousesView.vue`、`BatchesView.vue`、`CountsView.vue`、`AdjustmentsView.vue`、`TransfersView.vue`、`WavesView.vue`、`SalesOrdersView.vue`、`CustomersView.vue`、`UsersView.vue`、`FlowsView.vue` 以 `el-table` + `el-pagination` + `el-dialog` 实现增删改查，并通过 `onMounted` 拉取初始数据。
依赖方向单向向下：视图 → `@/api`（请求）/ `@/stores`（状态）/ `@/components`（复用 UI），不反向引用其他视图。
