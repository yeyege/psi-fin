- 路由集中定义在 `src/router/index.ts`，每个页面通过 `component: () => import(...)` 懒加载，并通过 `meta.title` 标注页面标题。
- 所有后端接口集中在 `src/api/index.ts` 按领域分块导出，统一返回 `{ code, data }` 结构，调用方直接解构 `data`。
- HTTP 请求通过 `src/api/client.ts` 封装，登录等冷启动接口显式设置 `timeout: 60_000` 以避免 Serverless 冷启动超时。
- 鉴权逻辑集中在路由守卫 `beforeEach`，通过 `localStorage` 中的 `psifin_token` 和 `psifin_user` 判断登录态与管理员角色。
- BI 相关图表与弹窗抽取为 `components/BiChart.vue`、`BiModal.vue`、`SummaryCards.vue` 通用组件，配合 `composables/useBiState.ts` 共享筛选状态。
- 业务视图按功能域拆分到 `views/` 下独立文件，复杂看板（如 BI）进一步拆分为 `views/bi/*` 子目录并按面板职责组织。
